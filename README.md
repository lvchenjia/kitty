# 🐱 Kitty Terminal 3D Graphics Engine | 终端 3D 图形学渲染引擎

> [!NOTE]
> 这是一个基于 **Kitty 终端图像协议 (Kitty Graphics Protocol)** 和传统字符终端的 **3D 实时渲染图形学项目**。它打破了传统终端只能显示粗糙 ASCII 字符的限制，通过自建的原生 PNG 极速压缩编码器，直接在终端中输出高分辨率、光滑、带复杂光影着色的 3D 渲染画面，在 Python 下达到 **30 FPS**，在 C 语言下可达到稳定的 **60 FPS**。

---

## 🎨 视觉震撼与核心特性

*   **⚡ 算法级压缩优化（吞吐量骤降 99%）**：
    通常 3D 渲染产生的大像素 raw 数据流高达数 MB，会瞬间挤爆 PTY (终端控制台) 的传输管道，导致极其严重的掉帧和延迟。本项目在 Python 与 C 中**完全从零实现了轻量级原生 PNG 压缩编码器**，结合内置的 `zlib` 快速无损压缩算法，将每帧大小从 **1.44MB** 压缩至 **10~20KB**。完美规避了通道拥堵，实现了终端上的丝滑渲染。
*   **🌓 电影级黏土着色器 (Cinematic Clay)**：
    `pixel_donut.c` 内置了高保真双光源系统、**半兰伯特 (Half-Lambert) 漫反射**、**Blinn-Phong 湿润微亮抛光镜面高光**，以及超细致的**菲涅尔边缘轮廓发光 (Fresnel Rim Light)**，让 3D 黏土模型极具厚重雕塑感和金属哑光质感。
*   **💎 水晶玻璃反射/折射着色器 (Crystal Glass)**：
    在 `pixel_donut.c` 中按空格键即可切换至水晶玻璃材质模式。该模式利用菲涅尔折射近似方程与超高次镜面反射高光亮点，通过**动态 Alpha 混合透明通道**实现了“中部极其通透、边缘强反光”的绝美 3D 水晶工艺品视觉效果。
*   **🎮 实时物理相机与旋转交互**：
    项目内多个渲染引擎集成了键盘的非阻塞式监听，支持实时通过键盘调整相机的三维平移（X/Y/Z轴）以及甜甜圈/立方体的三维旋转速度与方向。

## 🛠️ 构建与运行指南

### 1. 运行 Python 版本

Python 代码均为纯标准库实现，**零外部依赖**（无需安装任何第三方库），可直接运行。

*   **运行经典 ASCII 旋转立方体**：
    ```bash
    python3 cube.py
    ```
*   **运行实时可交互像素立方体**（需在支持 Kitty 协议的终端下运行，如 Kitty, WezTerm 等）：
    ```bash
    python3 pixel_cube.py
    ```
*   **运行 30帧 像素甜甜圈**：
    ```bash
    python3 pixel_donut.py
    ```

### 2. 编译并运行高性能 C 版本 (`pixel_donut.c`)

C 语言版本运用了系统级的 `zlib` 压缩库，可实现稳定的 60 FPS 超清渲染。

*   **在 macOS / Linux 上编译**：
    确保系统已安装有 `gcc` 或 `clang`。由于引用了 `math.h` 的三角函数和 `zlib` 压缩，编译时需要链接相应的库：
    ```bash
    gcc -O3 pixel_donut.c -o pixel_donut -lm -lz
    ```
*   **运行程序**：
    ```bash
    ./pixel_donut
    ```

> [!TIP]
> **终端兼容性建议**：
> 带 `pixel_` 前缀的程序依赖 **Kitty Graphics Protocol** 图像输出。建议使用以下终端以获得完美的视觉输出：
> *   **Kitty** (原生支持，效果最佳)
> *   **WezTerm** (原生支持，效果极佳)
> *   **Ghostty** (原生支持，表现优异)
>
> 若您在非兼容终端（如 macOS 默认 Terminal、VS Code 内置终端）运行像素版，程序可能会无法解析图形转义码而输出 Base64 乱码字符。若遇到此情况，直接运行常规的 `cube.py` 字符线框版即可获得完美体验。

## 🔬 图形学硬核技术拆解

1.  **3D 空间变换与投影**：
    通过定义 $8$ 个物空间顶点/甜甜圈环面参数，使用三维旋转矩阵进行绕坐标轴的连续线性变换。计算后通过经典的透视投影公式：
    $$x_p = \frac{W}{2} + \frac{x \cdot \text{scale} \cdot \text{Aspect}}{z + d}$$
    将三维世界中的物体缩放到终端二维屏幕视口。
2.  **布雷森汉姆直线算法 (Bresenham's Line Algorithm)**：
    在 `pixel_cube.py` 中，通过纯整数增量算法快速光栅化绘制 3D 棱边线条，并设计了 3x3 粗化像素笔刷，彻底打碎并消除了拉伸导致的边缘模糊。
3.  **高精度单像素 Z-Buffer（深度缓冲检测）**：
    为了使甜甜圈具有绝对逼真的前后遮挡和明暗，甜甜圈渲染中引入了与物理引擎等同的 `Z-Buffer` 机制。只有当前算出的像素的深度倒数 $ooz$ 大于缓冲区内已有值时才写入像素，完美防止透射和乱序越权渲染。
4.  **半兰伯特与镜面高光反射着色模型**：
    *   **漫反射（Half-Lambert）**：
        相比常规兰伯特，引入了 $0.5 \cdot \text{dot} + 0.5$ 映射，使暗部阴影边缘更柔和舒适，更符合黏土材质特征。
    *   **镜面高光（Blinn-Phong）**：
        基于半角向量 $H$ 与表面法线 $N$ 的点积进行高次幂计算，生成细小刺眼的白瓷反射亮点。
    *   **轮廓发光（Fresnel Rim Light）**：
        应用菲涅尔效应近似公式：
        $$\text{Fresnel} = (1 - (N \cdot V))^{3.5}$$
        为物体的切线轮廓面加上一圈完美的边缘白光。
5.  **内存级 PNG 极速编码与 Base64 静默流**：
    在 C 语言版本中，每一帧通过自定义的 `encode_png` 构建原生 PNG 头部块（IHDR）、压缩图像数据块（IDAT）和结束块（IEND）。通过高速 Base64 编码后，采用大缓冲静默包单次 `fwrite`，大幅消减 I/O 阻塞。
